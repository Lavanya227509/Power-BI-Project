# 🏥 Patient Health Analysis Dashboard

## 📌 Project Overview
This project focuses on analysing patient health data using Microsoft Power BI. It provides insights into patient demographics, BMI, medications, ethnicity, and medical conditions.

## 🎯 Project Objectives
- Analyse patient demographics.
- Understand BMI distribution.
- Identify frequently used medications.
- Analyse common health conditions.
- Support data-driven healthcare decisions.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| 📊 Microsoft Power BI | Dashboard creation |
| 📗 Microsoft Excel | Data cleaning |
| 🔄 Power Query | Data transformation |
| 📈 Data Visualization | Visual analysis |

## 📊 Dashboard Features
- Gender-wise patient analysis
- BMI analysis by ethnicity
- Medication usage analysis
- Patient medical conditions
- Interactive filters and slicers

## 🔍 Four Types of Analytics

1. **Descriptive Analytics** – What happened?
2. **Diagnostic Analytics** – Why did it happen?
3. **Predictive Analytics** – What might happen?
4. **Prescriptive Analytics** – What should be done?

## 💡 Key Insights
- Lisinopril has the highest medication count among displayed medications.
- White ethnicity has the highest BMI sum in the displayed chart.
- Asthma, Hypertension, and Back Pain are highlighted conditions.

## 🏁 Conclusion
This dashboard transforms patient health data into meaningful insights and helps support better healthcare decision-making.
